# 🚗 Automotive Sales Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze automotive sales, profit performance, vehicle brands, fuel types, transmission preferences, and payment methods.

The dashboard consolidates important performance indicators and visualizations into a single report for exploring automotive sales performance.

## 🎯 Project Objectives

- Monitor overall sales, profit, and profit margin.
- Analyze monthly sales and profit trends.
- Compare sales performance across automotive brands.
- Examine sales distribution by fuel type.
- Compare automatic and manual transmissions.
- Analyze sales by geographical region.
- Explore payment method distribution.
